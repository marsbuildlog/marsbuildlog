## Currently building: SheetDo

**[sheetdo.com](https://sheetdo.com)** — *Master spreadsheets by doing.*

A free, in-browser practice hall for Excel and Google Sheets formulas. You type a real formula into a real sheet and get pass/fail in milliseconds — nothing to install, no account, and no server evaluating your answer.

- **[Practice hall](https://sheetdo.com/practice/?utm_source=github&utm_medium=profile&utm_campaign=evergreen-links)** — 35 graded challenges, from everyday arithmetic to XLOOKUP questions that show up in job interviews
- **[Formula guides](https://sheetdo.com/formulas/?utm_source=github&utm_medium=profile&utm_campaign=evergreen-links)** — VLOOKUP, XLOOKUP, IF, IFERROR, SUMIF, COUNTIF, LEN, MID and more
- **[Micro-tools](https://sheetdo.com/tools/?utm_source=github&utm_medium=profile&utm_campaign=evergreen-links)** — CAGR calculator, freeze panes, merge cells, duplicate highlighter, dropdowns
- **[Cheatsheets](https://sheetdo.com/cheatsheets/?utm_source=github&utm_medium=profile&utm_campaign=evergreen-links)** — formulas and keyboard shortcuts you can print

Built with Astro (fully static) and Univer Sheets (the formula engine runs client-side). Available in English, 简体中文, 繁體中文 and 日本語.
